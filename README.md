# “Global Development Measurement – Cluster Analysis”
Worked on a global development measurement dataset containing economic, health, energy, and business related indicators across multiple countries. Performed data cleaning, preprocessing, feature selection, and EDA using Python. 
Implemented unsupervised clustering models, including DBSCAN, to group countries and identify outliers. 
Evaluated clustering results and applied PCA for dimensionality reduction and visualization. Deployed the clustering model using Streamlit, enabling interactive analysis, parameter tuning, and country-wise grouping outputs.

Tools & Technologies : Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Unsupervised Learning, DBSCAN, PCA, Streamlit, Feature Selection, Scaling, EDA
